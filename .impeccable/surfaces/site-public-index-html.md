# perchbrowser.com landing page (beta)

Mode: Persuade. Audience: Mac users who live in the browser and already pay for ChatGPT, Claude or Grok. Action: download the v0.1.0 beta (GitHub pre-release DMG). Proof: real screenshots of the real app; no invented numbers, speed stays as stated 1.0 targets.

## Direction contract (redesign, 2026-11-12)

THESIS: The site is a Perch window. Its header is Perch's tab strip on the canvas colour (the nav items are tabs, the active "Perch" tab joins the page), and the page sits on the card colour beneath it. The first screen is Perch's new tab page answering "What is Perch, and can I try it?", ending in an approval card whose confirm button is the download.

OWN-WORLD: DESIGN.md tokens exactly: Ink (canvas #0E0E0D, card #141413, elevated #1A1A18, ink #F2F0EA, mute #8B8A87) for dark visitors, Paper (#F7F5EF / #FBFAF6 / #EFECE4, ink #16161A) for light ones, Blue accent #4C8DFF / #2A63CC. Newsreader for the hero and closing headline only, Geist for UI and section headings, Geist Mono for versions, hosts and code. Radii 8/12/16 as in the app.

STORY: Product visuals are drawn in HTML from the same tokens (the side chat with an approval card over a stand-in mail site, Permissions, Models and Privacy settings panels, the glass command bar, five theme windows), so they match the current build in both themes. A Settings-grouped index lists every feature in the beta. Speed stays as stated 1.0 targets.

MOTION: one moment: the question types into the box, then the answer, card and window arrive. Nothing else animates except the breathing perch dot on the working tab. Instant under Reduce Motion. No scripts (the CSP forbids them).
