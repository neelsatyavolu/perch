# Perch

Perch is a fast, private, open-source AI browser for macOS, built on Chromium so every Chrome extension works. An agent in the sidebar can use the sites you are logged into with your own ChatGPT, Claude or Grok account, and nothing leaves your Mac unencrypted.

Perch is in early development. To build it, see [docs/building.md](docs/building.md). The design is in [docs/superpowers/specs/2026-11-02-perch-design.md](docs/superpowers/specs/2026-11-02-perch-design.md).
