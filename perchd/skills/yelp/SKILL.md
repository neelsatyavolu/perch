# Yelp

## Go straight to the page

- Search: `https://www.yelp.com/search?find_desc=<what>&find_loc=<city, state or zip>`
- Sort by rating or by number of reviews: add `&sortby=rating` or `&sortby=review_count`
- A business: `https://www.yelp.com/biz/<slug>`; newest reviews first: add `?sort_by=date_desc`

## Read results quickly

Check the location chip shows the place the task names: Yelp fills in a location from the network otherwise. Then read name, rating, review count, price level and neighbourhood for each result before opening any.

## Notes

- Results marked Sponsored are ads; leave them out unless asked.
- Weigh the rating by the number of reviews, and read a few recent reviews before recommending a place: the newest ones show closures, new owners and changed quality.
- Hours on Yelp can be stale. For a visit soon, check the business's own site or Google Maps too.
- If Yelp shows a bot check, use Google Maps for the same search instead of trying to get past it.
