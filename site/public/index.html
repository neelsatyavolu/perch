A fast, private, open-source browser for Mac

Perch has an AI agent that can use the sites you're signed in to, running on your own ChatGPT, Claude or Grok subscription.

In development · macOS on Apple silicon

An agent that asks before it acts

Open a side chat on any tab and say what you need done. The agent reads the page, clicks and types in it, and lists each step as it goes. A side chat belongs to its tab: switch tabs and you see that tab's chat, switch back and yours is where you left it, draft included.

Approval cards
Before anything is sent, posted, bought or deleted, Perch shows exactly what will go out, such as the message text or the order total. The button names the action, like Send message.
Permission modes
Ask waits for you on every change. Guard, the default, reads, searches and fills forms on its own and asks before it sends anything. Skip confirmation runs without asking, but payments and password changes still wait for you.
Site rules
Mark a site always allow, always ask or never touch. Never touch keeps the agent off a site entirely, your bank for example.
An audit log
Every action the agent takes is recorded with the time, the site, which client asked for it and whether you approved it.

Bring the model you already pay for

Perch has no paid plan and no model of its own. Connect what you have, and pick a different model for each kind of work: a quick one for summaries, a stronger one for planning, one that can read images.

Chromium underneath

Perch is a fork of Chromium, the engine Chrome is built on. Extensions from the Chrome Web Store install and run as they do in Chrome, and sites behave the same way.

Perch copies bookmarks, history, passwords and cookies from the browser you use now, reinstalls the extensions you had in a Chromium browser, and brings memory, skills and chats over from Aside.

Private without extra setup

Perch works without an account, and what it stores stays on your Mac unless you choose to sync.

No telemetry by default
Perch sends no usage data unless you opt in. Settings lists every background connection it makes, such as extension updates and Safe Browsing lists, each with its own switch.
A blocker built in
Ads and trackers are blocked with the EasyList and EasyPrivacy rules. Cookie banners are rejected where the site offers a way to reject, and tracking parameters such as utm_ and fbclid are taken off links.
Sync the server can't read
Sync is optional. Your data is encrypted on your Mac before it leaves, and the server keeps only ciphertext, sizes and timestamps.
Secrets stay out of the model
When a site asks for a login, the browser fills saved passwords, cards and one-time codes itself. The model only learns that the field was filled.

Other agents can use it too

The perch command and its MCP server let Claude Code, Codex and agterm tabs hand Perch a whole task or work a tab step by step. One command sets up each of them.

Every outside client gets its own permission mode, Guard unless you change it, and you can revoke any of them in Settings.

# add Perch's skill and MCP server
perch skill install claude

# hand a whole task to an agent
perch exec "Add the Readwell receipt to my budget sheet"

# or drive a tab yourself
perch open https://example.com
perch snapshot
perch click e12

Open source, MIT licensed

All of Perch is on GitHub: the Chromium patches, the agent, the interface and the sync server. You can run your own copy of the sync server on Cloudflare and point Perch at it, and your data stays end-to-end encrypted there too.

Perch is in development, and the first release comes once every feature works. Watch the repository to hear when it's out.
