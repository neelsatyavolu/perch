The browser that asks before it acts

What is Perch, and can I try it? SearchAsk

Perch's own new tab page · Tab Google · ⌘↵ Ask

A fast, private, open-source browser for Mac, built on Chromium so every Chrome extension works. Its agent uses the sites you're signed in to, on your own ChatGPT, Claude or Grok account, and asks before anything is sent, posted, bought or deleted.

It shows you what goes out

Open a side chat on any tab and say what you need done. The agent reads the page, clicks and types in it, and lists each step. Before anything is sent, posted, bought or deleted, it stops on a card with the exact message or total, and the button names the action.

Permission modes
Ask waits on every change. Guard, the default, reads, searches and fills forms on its own and asks before it sends. Skip confirmation runs without asking, but payments and password changes still wait for you.
Site rules
Mark a site always allow, always ask or never touch. Never touch keeps the agent off a site entirely, your bank for example.
Chats stay with their tab
Switch tabs and you see that tab's chat; switch back and yours is where you left it, draft included.
An audit log
Every action is recorded with the time, the site, which client asked and whether you approved it.

Bring the model you already pay for

Perch has no paid plan and no model of its own. Connect what you have, and pick a model for each kind of work: a quick one for summaries, a stronger one for planning, one that can read images.

Claude
Perch runs the Claude Code you already have installed, which keeps its own sign-in. Perch never reads its tokens.
ChatGPT and Grok
Sign in with your account.
API keys and local models
Anthropic, OpenAI, xAI, Gemini and OpenRouter keys, or any OpenAI-compatible server such as Ollama or LM Studio on your Mac.

A new tab that picks up where you left off

Type to search, or press ⌘↵ to ask. Your recent chats sit under the box, and a rail on the left keeps the rest, the way Aside does it.

Quiet chrome, your colours

The tab strip, toolbar and menus stay Chromium's own native code, redrawn so they step back and let the sites carry the colour. Pick one of five themes and five accents; Contrast turns on by itself with macOS Increase Contrast.

Speed comes first

Perch keeps Chromium's engine as it is and adds as little as it can on top. Each release will be measured against Chrome built from the same Chromium version, and 1.0 ships only when it clears this bar.

Private without extra setup

Perch works without an account, and what it stores stays on your Mac unless you choose to sync.

No telemetry by default
Nothing about how you use Perch is sent unless you opt in. Settings lists every background connection, each with its own switch.
A blocker built in
EasyList and EasyPrivacy block ads and trackers before they load. Cookie banners are rejected where the site allows it, and tracking parameters such as utm_ and fbclid come off links.
Sleeping tabs
Tabs you haven't used in a while go to sleep and give their memory back, and wake when you click them.
Sync the server can't read
Sync is optional and end-to-end encrypted. The server keeps only ciphertext, sizes and timestamps, and you can run your own.

Chromium underneath

Extensions from the Chrome Web Store install and run as they do in Chrome, and sites behave the same way. Perch copies bookmarks, history, passwords and cookies from the browser you use now, and brings memory, skills and chats over from Aside.

Other agents can use it too

The perch command and its MCP server let Claude Code, Codex and other agents hand Perch a whole task or work a tab step by step. Each one gets its own permission mode, Guard unless you change it, and you can revoke any of them in Settings.

# add Perch's skill and MCP server
perch skill install claude

# hand a whole task to an agent
perch exec "Add the Readwell receipt to my budget sheet"

# or drive a tab yourself
perch open https://example.com
perch snapshot
perch click e12

Open source, MIT licensed

All of Perch is on GitHub: the Chromium patches, the agent, the interface and the sync server. This is a beta, so expect rough edges, and tell us what breaks.
