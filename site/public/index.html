The browser that asks before it acts

What is Perch, and can I try it? SearchAsk

Tab Google · ⌘↵ Ask

A fast, private, open-source browser for Mac, built on Chromium so every Chrome extension works. Its agent uses the sites you're signed in to, on the ChatGPT, Claude or Grok account you already pay for, and stops to ask before anything is sent, posted, bought or deleted.

It shows you what goes out

Open a side chat on any tab and say what you need. The agent reads the page, clicks and types in it, and lists every step. Before anything is sent, posted, bought or deleted, it stops on a card with the exact message or total, and the button names the action.

Three permission modes
Ask waits on every change. Guard, the default, reads, searches and fills forms on its own and asks before it sends. Skip confirmation runs straight through, but payments and password changes still wait for you.
Site rules
Mark a site always allow, always ask or never touch. Never touch keeps the agent off it entirely, your bank for example.
A chat for each tab
Switch tabs and you see that tab's chat. Come back and yours is where you left it, draft included.
Activity log
Every action is recorded with the time, the site, who asked and whether you approved it.

A browser first

Tabs, toolbar and menus are Chromium's own native code, redrawn so they step back and let the sites carry the colour. Extensions from the Chrome Web Store install and run as they do in Chrome.

Sleeping tabs
Tabs you haven't used in a while give their memory back and wake when you click them. You choose after how long, and which sites never sleep.

Small things that come built in

Perch's own tools ship with it and can each be turned off in Settings.

  • Reader viewStrips a page down to the article, set in Newsreader.
  • Picture in pictureA playing video follows you when you switch tabs.
  • Video keysChange the speed of any video from the keyboard.
  • Link previewLook at a link without leaving the page.
  • ScreenshotsCapture a whole page, top to bottom, in one image.
  • BackrowWatch Netflix, YouTube and others in sync with friends, with an encrypted chat beside the video.
  • CaveatlyReads a site's terms and privacy policy and grades what they say, using your own Gemini key.
  • ImportsBookmarks, history, passwords and cookies from your current browser, and memory, skills and chats from Aside.

Private without extra setup

Perch works without an account. What it stores stays on your Mac unless you choose to sync, and nothing about how you use it is sent unless you opt in.

Sync the server can't read
Sync is optional and end-to-end encrypted. The server keeps only ciphertext, sizes and timestamps, and you can run your own.
Every connection listed
Settings shows each background connection Perch makes, each with its own switch.
Your data, portable

It learns your routine, and other agents can use it

The perch command and its MCP server let Claude Code, Codex and other agents hand Perch a whole task or work a tab step by step. Each gets its own permission mode, and you can revoke any of them.

Memory
Perch can learn from your chats and browsing history, if you allow it, and tidies what it knows overnight. You can read and edit all of it.
Routines
Tasks that run on a schedule, such as summarising unread mail each morning.
Skills and MCP
Add skills and MCP servers, or import the ones your other tools already use.
# add Perch's skill and MCP server
perch skill install claude

# hand a whole task to an agent
perch exec "Add the Readwell receipt to my budget sheet"

# or drive a tab yourself
perch open https://example.com
perch snapshot
perch click e12

Speed comes first

Perch keeps Chromium's engine as it is and adds as little as it can on top. Each release will be measured against Chrome built from the same Chromium version, and 1.0 ships only when it clears this bar.
