An agent that remembers and hands you the work

It keeps its tabs out of your way, reads the documents behind links, gives you files you can keep, and learns what matters to you. You review what it remembers and can undo any of it.

  • Agent TabsThe agent works in tabs of its own. Open one and its chat sits beside it.
  • Reads documentsPDFs, slides, Word and Excel files behind a link, signed in as you.
  • Files you keepNotes, tables and zips, with Download and Show in Finder.
  • Queue and steerSend the next message while it works, or change its course.
  • Build my memoryResearches you from your mail, accounts and history. You approve every fact.
  • Recall as it worksBrings up what it knows for each message and the site you're on.
  • Undo for memoryEvery change to memory is listed, and any of it can be taken back.
  • Private chatsLeave no memory, files or activity log behind.

Perch is private without extra setup

The perch command and MCP server for other agents

The perch command lets Claude Code, Codex and other agents hand Perch a whole task or work a tab step by step. Each gets its own permission mode, and you can revoke it.

Terminal
# add Perch's skill and MCP server to Claude Code
perch skill install claude

# hand a whole task to an agent
perch exec "Add the Readwell receipt to my budget sheet"

# or drive a tab yourself
perch open https://example.com
perch snapshot
perch click e12

Perch's speed bar for 1.0
