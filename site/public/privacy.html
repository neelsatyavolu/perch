Site privacy

This note covers the perchbrowser.com website. For how the Perch browser handles your data, see Privacy on the home page.

The site sets no cookies, runs no analytics and no JavaScript, and loads nothing from other servers. The fonts and images come from perchbrowser.com itself.

The site is hosted on Cloudflare. To deliver a page, Cloudflare receives your IP address and the request, as any web host does. The site's own code keeps no logs.

Questions go to the issue tracker on GitHub.
